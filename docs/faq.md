# Swift Drop technical FAQ

## Is this the production source code?

No. This is a public technical companion repository. The production application is
private because it contains implementation code, integrations, and deployment details
that should not be exposed.

## Which languages are supported?

The public website supports English at root paths and Arabic under `/ar`. For example,
the English services page is `/services` and the Arabic equivalent is `/ar/services`.

## Does the website trust the price sent by the browser?

No. The server recalculates the booking amount from validated booking data before a
booking is confirmed.

## Can I use this repository as a public API?

No. It documents public behavior but does not define a public API or grant access to
private endpoints. Use the [live website](https://swiftdrop.express/) for customer
actions and the [contact page](https://swiftdrop.express/contact) for business or
integration enquiries.

## Does publishing documentation guarantee better rankings?

No. Useful public documentation can improve trust, discovery, and referral traffic,
but search visibility depends on many factors: crawlability, relevant content, local
presence, customer experience, and genuine references from other sites.

## Where can I ask about a delivery?

Use the [Swift Drop contact page](https://swiftdrop.express/contact) or the contact
options shown on the live website.
