# Security policy

This repository contains public documentation and intentionally excludes production
credentials, customer records, and private application source.

If you discover a security issue involving Swift Drop, do not publish sensitive details
in a public issue. Use the [Swift Drop contact page](https://swiftdrop.express/contact)
and include enough information for the team to reproduce the issue safely.

Never include API keys, payment credentials, webhook secrets, personal data, or private
URLs in a documentation pull request.
